# Design Engineering, Superpowers & Design Suite Configuration for Antigravity

This repository is configured with **Design Engineering (`emil-design-eng`) as the #1 Top Priority** for all interface, UI/UX, micro-interaction, animation, and frontend craftsmanship, alongside **Apple Design**, **Frontend Design**, **Impeccable**, and **Superpowers**.

## Active Skills & Workflow Rules

- **🚨 TOP PRIORITY — Design Engineering (`emil-design-eng`)**: Must be prioritized over all other design decisions. Apply Emil Kowalski's design-engineering philosophy:
  - *Taste is trained, not innate* — unseen details compound into something that feels right.
  - *Concrete UI guidance*: Avoid `transition: all`, never animate from zero scale (use `scale(0.95); opacity: 0`), use `ease-out` for instant response, enforce `:active` press states (`scale(0.97)`), scale popovers from triggers, coordinate spring physics and layout animations.
  - *Mandatory review format*: When reviewing UI code, use the required Markdown table with `| Before | After | Why |`.
- **Apple Design Standards**: Apply `apple-design` for fluid, physics-based gesture interactions, spring animations, direct manipulation (1:1 tracking), translucent materials/depth (blur, vibrancy), and interruptible momentum transitions.
- **Impeccable Design Standards**: Apply `impeccable` for design audits, UX polish, visual hierarchy, craft floors, typography refinement, and preventing generic AI slop.
- **Frontend Design Excellence**: Apply `frontend-design` for intentional aesthetics, bespoke typography, curated color systems, and eliminating generic AI templated defaults.
- **Core Engineering Workflow**:
  - *Brainstorming & Planning*: Brainstorm specifications and write clear step-by-step plans before coding (`brainstorming`, `writing-plans`).
  - *TDD (Test-Driven Development)*: Follow Red-Green-Refactor with automated tests (`test-driven-development`).
  - *Systematic Debugging*: Perform structured root cause analysis before applying fixes (`systematic-debugging`).
  - *Verification*: Verify all changes and run tests before finalizing (`verification-before-completion`).
